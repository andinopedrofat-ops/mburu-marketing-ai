# FLYER TEMPLATE SYSTEM — MBURUCUYA FITNESS CENTER
## Visual Design Briefs · Paraguay Market

---

## DESIGN STANDARDS FOR ALL FLYERS

### Color Application
- **Primary background**: Deep Blue #0A1628
- **Primary text**: White #FFFFFF or Energetic Yellow #FFD600
- **Accent elements**: Yellow badges, borders, or geometric shapes
- **Never**: Red or green as primary colors (reserved for Paraguay flag campaigns only)

### Typography
- **Headlines**: Ultra-bold condensed (Bebas Neue or equivalent) — ALL CAPS
- **Sub-headlines**: Bold sans-serif (Inter Bold or equivalent)
- **Body text**: Regular sans-serif — maximum 2 lines of body per flyer
- **Pricing**: Extra-bold, large, in rounded pill/badge containers (as seen in current brand)

### Layout Principles
- Vertical format (9:16) for Stories and Reels thumbnail
- Square format (1:1) for Feed posts
- Maximum 3 visual elements per flyer (background + headline + accent)
- Pricing always in yellow pill-shaped badges on blue background (brand standard confirmed)
- Logo top-left or bottom-center — never compete with headline

## FLYER TYPE 01 — PRICING/MODALIDADES

**Purpose**: Communicate class offerings and prices clearly
**Format**: Carousel (2 slides) — Modalidades + Combos

**Slide 1 Layout**:
```
[HEADLINE: MODALIDADES — yellow, ultra-bold, top center]
[4 service blocks arranged in 2×2 grid]
[Each block: service name (gold badge) + price (blue pill with white text)]
[Bottom: logo + thin yellow decorative element]
[Background: Deep Blue with subtle gym photo overlay, 60% opacity]
```

**Slide 2 Layout**:
```
[HEADLINE: COMBOS — yellow, ultra-bold, top center]
[Combo blocks: 2 main combos + specialty section below]
[Same pill/badge system]
[Background: Deep Blue with gym photo, slightly different angle]
```

**Caption Formula**:
```
💥 Elegí la modalidad que va con vos.

Cross · Funcional · Musculación
Halterofilia · Gimnasia

Matrícula anual: GS. 100.000
Consultá por combos y descuentos.

👇 Escribinos para más información.
```

## FLYER TYPE 02 — SCHEDULE/HORARIOS

**Purpose**: Show class availability; counter "I don't have time" objection
**Format**: Carousel (2 slides) — Crosstraining + Funcional

**Layout**:
```
[HEADLINE: HORARIOS — yellow, ultra-bold, top center]
[Class type label: gold rounded badge]
[Time slots: white text in blue bordered pills, arranged in 2-column grid]
[Bottom: "Encontrá tu turno" + logo]
[Background: Deep Blue + gym energy overlay]
```

**Caption Formula**:
```
Desde las 5:50am hasta las 8:00pm.

Nadie tiene excusa de horario en MBURU.

Encontrá tu turno y reservá lugar.
Link en bio → o escribinos directamente.
```

## FLYER TYPE 03 — PROMOTIONAL OFFER

**Purpose**: Drive enrollment during campaigns
**Format**: Single image or Story

**Layout**:
```
[Top third: Offer headline — yellow ultra-bold on deep blue]
[Center: Offer details — white bold on blue]
[Bottom third: Urgency element — "Hasta el [fecha]" in yellow badge]
[Decorative: gold corner elements (as seen in brand)]
[Logo: bottom center, white]
```

**Caption Formula**:
```
[OFFER HOOK — one line that creates desire]

[OFFER DETAILS — specific, clear]

Quedan [X] lugares.
Cierra el [fecha].

Escribinos HOY y te reservamos el tuyo.
```

## FLYER TYPE 04 — SEASONAL/CAMPAIGN

**Purpose**: Special dates, campaigns, community events
**Format**: Varies — see /campaigns folder for specific briefs

**Key design note**: Seasonal campaigns may introduce accent colors
(e.g., Paraguay flag colors for Independence Day, red/pink for Valentine's)
but Deep Blue must remain the dominant background color.
Yellow must remain the primary headline color.
Brand identity is non-negotiable even in seasonal contexts.
