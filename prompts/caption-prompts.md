# CAPTION GENERATION PROMPTS — MBURUCUYA FITNESS CENTER
## Prompt Templates for AI-Assisted Caption Writing

---

> **How to use**: Copy the prompt template, fill in the [brackets], and use with
> any AI assistant to generate on-brand MBURU captions.
> Always review and refine AI output — these prompts produce drafts, not finals.

## MASTER SYSTEM PROMPT
*Paste this before any caption prompt to activate brand context:*

```
You are writing social media captions for Mburucuya Fitness Center (MBURU),
a CrossFit-inspired community gym in Paraguay. The brand voice is:
direct, warm, real, and cinematic. Use Rioplatense Spanish ("vos" form,
not "tú"). Never use generic fitness clichés. Always anchor to a specific
human emotion before any brand message. The brand's primary emotional
promise is: you will become someone you respect. Use deep empathy first,
then motivation. Never be corporate or salesy.
```

## CAPTION PROMPT 01 — ONE-WORD IDENTITY POST

```
[SYSTEM PROMPT]

Write an Instagram caption for a post with a one-word headline: "[WORD]"
(e.g., RESILIENCIA, DISCIPLINA, COMUNIDAD) over a photo of a real gym member.

The caption should:
1. Open with a one-line observation about what that word really means (not the dictionary definition — the lived experience)
2. Connect it to the experience of training at a gym community
3. Describe a specific small real moment that embodies this word
4. End with a soft invitation, not a hard sell
5. Include ONE hashtag block at the end

Tone: Warm, poetic, real. Like a coach who genuinely cares.
Length: 4-6 short paragraphs. No bullet points.
Language: Spanish (vos form, Paraguayan register)
```

## CAPTION PROMPT 02 — MEMBER TRANSFORMATION STORY

```
[SYSTEM PROMPT]

Write an Instagram caption for a before/after transformation post featuring
a real member named [NAME], who [SPECIFIC ACHIEVEMENT — e.g., "lost 14kg 
over 5 months" / "did their first unassisted pull-up" / "now trains 4x/week 
after never exercising before"].

Context about them: [ANY RELEVANT CONTEXT — age, job, family situation, 
what motivated them to start, what their biggest struggle was]

The caption should:
1. Open with the result (specific, not vague)
2. Tell the story backwards — result first, then the struggle
3. Include one specific detail that makes the story undeniably real
4. Let the member "speak" with one direct quote (in quotes)
5. Close with an invitation framed as: "if someone like [NAME] could..."

Tone: Proud, warm, specific. Never preachy.
Length: 5-7 paragraphs.
Language: Spanish (vos form)
```

## CAPTION PROMPT 03 — MYTH-BUSTING CAROUSEL

```
[SYSTEM PROMPT]

Write an Instagram caption for a carousel that busts this fitness myth:
"[MYTH — e.g., 'You need to be fit before joining a gym']"

The caption should:
1. Open by stating the myth as if agreeing with it (hook)
2. Create a pattern interrupt in line 2
3. Briefly summarize the truth covered in the carousel
4. Invite them to swipe and save

Tone: Authoritative but not condescending. Like a smart friend, not a lecturer.
Length: 3-4 paragraphs.
Language: Spanish (vos form)
```

## CAPTION PROMPT 04 — PROMOTIONAL OFFER

```
[SYSTEM PROMPT]

Write an Instagram caption for a promotional post offering [OFFER DETAILS,
e.g., "first class free" / "January promo: join without enrollment fee"].

Context: [CAMPAIGN CONTEXT — seasonal, limited spots, etc.]

The caption should:
1. Open with an emotional hook (NOT the offer)
2. Present the offer clearly in paragraph 2
3. Add real urgency (specific number of spots or specific deadline)
4. Close with ONE clear CTA — exactly what to do, how

Rules:
- No "¡Aprovechá!" (cliché)
- No more than 1 exclamation mark total
- Urgency must feel real, not manufactured
- CTA must be the final line, not buried in the middle

Length: 3-4 short paragraphs.
Language: Spanish (vos form)
```

## CAPTION PROMPT 05 — MONDAY MOTIVATION

```
[SYSTEM PROMPT]

Write an Instagram caption for a Monday morning post. The visual shows
[VISUAL DESCRIPTION — e.g., "early morning class at 5:50am, high energy"].

The caption should:
1. Open with a time reference or the word "Lunes" used powerfully
2. Reframe Monday as an identity moment, not a chore
3. Connect training to something larger than fitness (who they're becoming)
4. Close with an invitation, not a command

Tone: Warrior energy that feels warm, not aggressive.
Length: 3-4 paragraphs.
Language: Spanish (vos form)
Do NOT use: "¡Arriba!", "¡Vamos!", "¡A darle!"
```

```

The caption should:

2. Name 1-2 specific things that make this community unique

Tone: Warm, celebratory, genuine pride.
Length: 3-4 paragraphs.
Language: Spanish (vos form)
Include tagging CTA: "Etiquetá a [someone relevant]..."
```

## CAPTION PROMPT 07 — EDUCATIONAL (TIPS/HOW-TO)

```
[SYSTEM PROMPT]

Write an Instagram caption for an educational carousel post about:
```

## CAPTION REVIEW CHECKLIST

Before publishing any AI-assisted caption:

- [ ] Voice sounds like MBURU, not generic fitness brand
- [ ] "Vos" form used correctly throughout (not "tú")
- [ ] No Argentinian-exclusive slang that wouldn't land in Paraguay
- [ ] Opens with emotion or tension, not with the offer
- [ ] Single clear CTA at the end
- [ ] Maximum 1 exclamation mark total
- [ ] No words from the prohibited list (see CLAUDE.md Section 02.4)
- [ ] Hashtags are in the first comment OR at the very end (never in the middle)
- [ ] Length feels right for the platform (Instagram captions: short paragraphs, white space)
