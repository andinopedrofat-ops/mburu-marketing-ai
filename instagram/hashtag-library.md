## HASHTAG RULES

1. **Maximum 10 hashtags per post** — quality over quantity
2. **Preferred placement**: First comment (not caption body) — keeps caption clean
3. **Never repeat** the same hashtag set two posts in a row — vary the mix
4. **Monitor performance**: Check which hashtags bring genuine reach (not bot accounts)
5. **Banned hashtags** (shadow-ban risk): #follow4follow #like4like #fitness100 and variations
6. **Research local competitors monthly** — identify which tags they're missing (opportunities)
